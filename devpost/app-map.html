Offline reference snapshot at commit c192bd6. This map describes the verified vibe-coding session flow.

What Explainit does

Explainit watches saved workspace edits, uses a bounded local MCP context server plus an agent skill to understand the newest edit, and opens a retro comprehension quiz. A developer can also route a prompt to @explainit for short host commentary.

Reference route: saved edit to quiz

  1. extension/src/extension.ts — onDidSaveTextDocument debounces the saved document and carries the newest insertion/deletion summary.
  2. service/src/server.ts — contextFromRequest asks the MCP client for the focused Git context, then POST /quiz calls the agent.
  3. service/src/agent.ts → extension/src/quiz-panel.ts — the agent returns four mixed questions; the webview renders answers, feedback, score, and the Trust Receipt.

To change this, start here

  • Change automatic trigger timing or cooldown in extension/src/extension.ts.
  • Change question personality, difficulty, or format rules in service/src/agent.ts and .agents/skills/explainit-host/SKILL.md.
  • Change grading, loading, feedback, or receipt presentation in extension/src/quiz-panel.ts.
  • Change the bounded workspace boundary in service/src/mcp/server.ts and service/src/workspace/git.ts.

A practice to reuse

When an older Git diff caused vague questions, the implementation added an observable latest-edit signal from the editor and then verified it through a real Copilot save. For future agent-built features, define the newest event you want to explain, pass it through a narrow contract, and test that event—not just the accumulated repository state.

Run it again

From the repository root, run npm run dev:service, press F5 to launch the Extension Development Host, open a Git-tracked file, and save a meaningful edit. Use @explainit in VS Code Chat for prompt-level host commentary.
